# SOFTWARE REQUIREMENTS SPECIFICATION (SRS)

## Project Title
Food Wastage Management System

## 1. Introduction

### 1.1 Purpose
The purpose of this project is to develop a website that helps reduce food wastage by connecting people or organizations having excess food with people or organizations who need food.

### 1.2 Scope
The Food Wastage Management System provides an online platform to:
- Register available excess food.
- Find available food donations.
- Request food.
- Manage food donation details.
- Track the status of food donations.

## 2. Users of the System

### 2.1 Food Donor
A donor can:
- Register and log in.
- Add details about excess food.
- Specify the quantity and location.
- Update or remove a food donation.

### 2.2 Food Receiver
A receiver can:
- Register and log in.
- View available food.
- Search for suitable food donations.
- Request available food.

### 2.3 Admin
The admin can:
- Manage users.
- View food donations.
- Monitor food requests.
- Update or remove inappropriate records.

## 3. Functional Requirements

### 3.1 User Registration and Login
- Users can create an account.
- Users can log in using their credentials.
- Users can log out securely.

### 3.2 Food Donation
- Donors can add food details.
- Donors can specify food quantity.
- Donors can provide the food location.
- Donors can provide the available time.

### 3.3 Food Search
- Receivers can view available food.
- Receivers can search for food based on location or availability.

### 3.4 Food Request
- Receivers can request available food.
- The system records the request.
- Donors can view food requests.

### 3.5 Donation Management
- Donors can update donation details.
- Donors can delete their food donation.
- The system can update the donation status.

### 3.6 Admin Management
- Admin can view registered users.
- Admin can monitor donations and requests.
- Admin can manage system records.

## 4. Non-Functional Requirements

### 4.1 Performance
The website should respond quickly to user requests.

### 4.2 Security
User account information and login details should be protected.

### 4.3 Usability
The website should have a simple and user-friendly interface.

### 4.4 Reliability
The system should store food donation and request information accurately.

### 4.5 Availability
The website should be available whenever users need to donate or request food.

## 5. Hardware Requirements

- Computer or laptop
- Keyboard
- Mouse
- Internet connection

## 6. Software Requirements

- Windows/Linux operating system
- Visual Studio Code
- Web browser
- Git
- GitHub

## 7. System Features

- User registration and login
- Food donation
- Food search
- Food request
- Donation status tracking
- Admin management

## 8. Expected Outcome

The system helps reduce food wastage by providing a platform for donating excess food and connecting donors with people or organizations that need food.

## 9. Conclusion

The Food Wastage Management System provides an efficient and user-friendly solution for managing excess food. It helps reduce food wastage and supports the redistribution of available food to people in need.
